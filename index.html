02 / CONSISTENCY LIMITS

การทดลองขีดจำกัดความข้นเหลว

กรอกค่า LL และ PL ที่ได้จากการทดลอง หรือเลือก NP เมื่อทดสอบแล้วพบว่าไม่เป็นพลาสติก

ตารางข้อมูลดิบ LL และ PL (Casagrande)

กรอก 3 จุดทดสอบ LL (จำนวนครั้งเคาะและน้ำหนักกระป๋อง) และ 2 จุด PL · LL จากเส้นถดถอย w กับ log₁₀(N) ที่ 25 ครั้ง

ครั้งNกระป๋อง (g)กระป๋อง + ดินเปียก (g)กระป๋อง + ดินแห้ง (g)ดินแห้ง (g)น้ำ (g)w (%)

ใช้ส่วนดินผ่าน No.40 (0.425 mm) · LL แบบหลายจุด: 3 จุดในช่วง 15–35 ครั้งและคร่อม 25 ครั้ง · PL 2 ครั้ง · เกณฑ์ความต่าง PL ≤ 1.40 จุดเปอร์เซ็นต์ เป็นเกณฑ์คัดกรองของเว็บ ไม่ใช่ใบรับรอง ASTM

คำนวณ water content จากน้ำหนักดิบ

02A / LOG SCALE

การกระจายขนาดเม็ดดิน

ขนาดเม็ดดิน (mm) บนแกนลอการิทึม เทียบกับร้อยละที่ผ่านตะแกรง · ป้ายกำกับแสดงเบอร์ตะแกรงและ % Passing (2 ตำแหน่ง)

เส้น % Passingจุดทดลองเส้นประสีทอง = D10 / D30 / D60

บนหน้าจอเล็กสามารถเลื่อนกราฟซ้าย–ขวาเพื่ออ่านตัวเลขได้

Cu = D60 / D10 · Cc = D30² / (D10 × D60)
02B / ATTERBERG

QUALITY CONTROL

ผลการตรวจสอบตามเกณฑ์

ตรวจสอบความครบถ้วนและความสมเหตุสมผลของข้อมูลการทดลอง เทียบค่าที่ได้กับเกณฑ์ พร้อมเหตุผลของแต่ละข้อ

กรอกข้อมูลและกดวิเคราะห์
รายการตรวจค่าที่ได้เกณฑ์ตรวจสอบสถานะเหตุผล

เกณฑ์ความต่างน้ำหนัก ≤ 0.50% และความต่าง PL ≤ 1.40 จุดเปอร์เซ็นต์ เป็นเกณฑ์คัดกรองภายในเว็บ การผ่านการตรวจสอบไม่ใช่การรับรองวัสดุหรือผลการทดลองทางวิศวกรรม
